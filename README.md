# Gemini GPT 

A modern Flutter application that integrates with Google's Gemini AI for intelligent conversations with persistent data storage.

## ✨ Features

- 🤖 **AI Chat Integration** - Powered by Google Gemini AI  
- 💾 **SQLite Database** - Local chat history storage  
- ⚙️ **SharedPreferences** - User settings persistence  
- 🎨 **Modern UI/UX** - Clean and intuitive interface  
- 📱 **Cross-Platform** - iOS & Android support  
- 🌙 **Dark/Light Theme** - Customizable appearance  
- 💬 **Conversation Management** - Multiple chat sessions  
- 🔒 **Offline Storage** - Data persists locally  
- 📊 **Chat Analytics** - Message statistics  
- 🔧 **Customizable Settings** - Personalized experience  

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (latest stable)  
- Dart SDK  
- Android Studio / VS Code  
- Google AI API Key
